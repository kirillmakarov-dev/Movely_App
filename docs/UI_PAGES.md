# Movely UI Pages

This is the initial page inventory for the product. It is not a design system and does not commit us to implementation details yet.

## Customer-facing pages

- Landing page
- Request creation wizard
- Request review page
- Account confirmation and phone verification page
- Customer dashboard / My Move
- Customer request detail page
- Premium offer inbox or offer section
- Request closed / expired state page
- Duplicate request warning modal

## Mover-facing pages

- Mover sign-up / sign-in
- Mover onboarding
- Business profile setup
- Marketplace
- Marketplace filters view or bottom sheet
- Request details page
- Buy lead confirmation / purchase success state
- Sold-out request state
- Wallet page
- Wallet transaction history
- Saved searches
- Mover profile
- Premium offer composer
- Premium offer edit / withdraw state
- Rejected-by-customer request state

## Admin-facing pages

- Admin sign-in
- Admin dashboard
- Request moderation / support review
- Lead refund review
- Pricing and configuration management
- Mover verification review

## Shared UI states and patterns

- Responsive cards
- Filter chips
- Bottom sheets on mobile
- Step-by-step wizard navigation
- Review summary blocks
- Locked data states
- Unlocked contact states
- Empty states
- Loading and error states
- Status badges
- Sold-out badges
- Version change banners
- Stale offer banners
- Cancellation confirmation dialogs
- Duplicate-risk banners
- Rejected-by-customer banners
- Blocked-mover states
- Sticky primary actions
