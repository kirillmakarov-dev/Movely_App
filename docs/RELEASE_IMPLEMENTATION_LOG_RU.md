## 3. Восстановлены проверки и языковая основа

Реализовано 2026-10-29:

- Удалён перевод через MutationObserver, который изменял принадлежащий React DOM, не обеспечивал обратный перевод и мог менять пользовательский текст.
- Поддерживаемая локаль явно задана в `src/lib/locale.ts`; документ и динамические счётчики используют иврит. Не создаются бессмысленные cookie/записи браузерного хранилища для неработающего переключения языка.
- Убрано синхронное исправление индекса шага через effect: отображаемый индекс вычисляется в допустимом диапазоне.
- Тесты формы проверяют фактические подписи на иврите; убраны `any` и неиспользуемый mock. Сценарий отказа в публикации при не подтверждённом телефоне дополнительно проверяет отсутствие вызова publish API.
- Из lint исключены результаты сборки dist и кэш .vinext; исходный код остаётся под проверкой. Кэш шрифтов не добавляется в Git.
- Тест с jsdom больше не называется доказательством мобильного layout: геометрия проверяется отдельно в браузере.

Результат проверки:

- Web: 15/15 тестов успешно.
- API: 66/66 тестов успешно, фильтр `Category!=PostgreSqlIntegration`; работа с реальной PostgreSQL этим прогоном не подтверждена.
- Общий ESLint: успешно, без ошибок и предупреждений.
- TypeScript после `next typegen`: успешно. Next production build: успешно.
- Восстановление зависимостей API продолжает сообщать об уязвимом System.Security.Cryptography.Pkcs 9.0.0. Обновление и проверка зависимостей — отдельный обязательный шаг до релиза.
